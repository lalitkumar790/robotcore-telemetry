Load a CSV from your device to visualize measured coordinate tracks, RSSI/SNR, timestamps, and basic data quality. The file is parsed locally in this browser; no upload, server request, or account is required.

◈
Local processing: the selected file stays in this browser tab. Do not share screenshots or exported files with precise coordinates unless you intend to disclose the location data. This inspector does not replace the formal validation pipeline.
