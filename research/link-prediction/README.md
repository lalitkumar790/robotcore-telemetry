# Link Prediction Workstream

Research question: can observed radio, geometry, and environment features predict link quality at unmeasured positions or future times?

## Prerequisites

- Validated location-linked measurements with radio configuration and session metadata.
- Baseline models and clearly defined target variables, such as RSSI, SNR, or packet delivery probability.
- Session/route/spatial holdout splits that reduce leakage from nearby measurements.
- Metrics appropriate to the target, uncertainty reporting, and comparison against simple baselines.
- Separate model-development data from final evaluation data.

## Important

This folder documents a future research stage. No model performance should be claimed until experiments, baselines, splits, and results are reproducible.
